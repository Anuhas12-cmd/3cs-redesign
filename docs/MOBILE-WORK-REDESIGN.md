# Mobile Selected Work showcase

Selected Work now uses a single interactive concept-artwork stage at widths up to 600px. Desktop Skiper30 and the tablet layout are unchanged.

- Layered artwork sheets, prominent project numbering and a compact visual index replace the long mobile project stack.
- Swipe, previous/next buttons, thumbnails and keyboard arrows select projects without autoplay.
- Project title, category, original concept label and external destination remain tied to the existing verified project data.
- The caption reserves two title lines to reduce movement between project names. Motion respects the reduced-motion preference; buttons remain available.
- Checked in Edge iPhone SE emulation at 375px: next selection, thumbnail selection, keyboard selection/focus, and touch-swipe wraparound from project 4 to project 1 worked.
- TypeScript and production build passed. A complete device matrix and context-specific assistive technology audit were not performed.
